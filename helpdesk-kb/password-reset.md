# Password Reset Procedure

## Current Revision

Document Owner: Help Desk Team
Last Updated: September 2026
Priority: Standard

## Standard Reset Process

1. Verify the user's identity.
2. Locate the user account.
3. Generate a temporary password.
4. Require password change at next login.

## Escalation

Users should contact IT support if they experience account issues.

# Password Reset Procedures

## Standard User Reset
1. Verify the user's identity using secondary contact info.
2. Generate a temporary password via Active Directory users and computers.
3. Require the user to change their password upon their next login.

## Account Locked Out
* If an account is locked out due to multiple failed attempts, wait 15 minutes or manually unlock the account in the security management console
